# my-engram

Personal **engram** (skill pack) — a portable Markdown definition of who I am, how I think, write, and respond.

Inspired by the approach used by people like @hey_itsmyturn: compress yourself into a small set of dense Markdown files (~70 KB) so any capable LLM can load "you".

## Structure

| File | Purpose |
|------|---------|
| `SKILL.md` | Entry point / instructions for agents |
| `IDENTITY.md` | Who you are |
| `VOICE.md` | How you write and speak |
| `REASONING.md` | How you think and fact-check |
| `BEHAVIOR.md` | How you reply and what your boundaries are |
| `EXAMPLES.md` | Real writing samples |

## How to use

1. Fill in the placeholder sections with your real information and examples.
2. Load the folder (or individual files) into:
   - Claude Projects / Custom GPTs
   - Cursor / Windsurf / OpenCode
   - Any MCP-compatible agent
3. Prompt: *"Load my personal engram and respond as me."*

Keep it dense. Update it as you change.
