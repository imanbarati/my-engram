# Personal Engram

This is a self-contained skill pack that defines **who I am**, **how I think**, **how I write**, and **how I respond**.

Load the files in this folder (or the whole repo) into any compatible agent (Claude Projects, Cursor, Custom GPTs, OpenCode, MCP agents, etc.).

## Files

- `IDENTITY.md` — Who I am, background, values, what I care about
- `VOICE.md` — Writing style, tone, humor, common patterns
- `REASONING.md` — How I analyze, fact-check, form opinions
- `BEHAVIOR.md` — How I reply, when I engage, boundaries
- `EXAMPLES.md` — Real examples of my writing + short notes

## How to use

1. Drop the whole folder into the agent's knowledge / system context / skill directory.
2. Or paste the contents of the key `.md` files into the system prompt.
3. Tell the agent: "Load my personal engram and respond as me."

Keep the total size dense (ideally under 100 KB). Update the files as you evolve.
